# Payroll Management System Using Core Java

## 📌 Overview

The **Payroll Management System** is a Java-based project developed to strengthen and demonstrate my understanding of Core Java programming and Object-Oriented Programming (OOP) concepts.

The project applies fundamental Java principles to a practical payroll-management scenario, focusing on structured programming, class design, code readability, and logical problem-solving.

## 🎯 Objectives

- Develop a strong understanding of Core Java fundamentals.
- Apply Object-Oriented Programming concepts in a practical project.
- Understand how classes and objects model real-world entities.
- Improve programming logic and problem-solving skills.
- Practise writing modular, maintainable, and readable Java code.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Core Concepts:** Core Java and Object-Oriented Programming
- **IDE:** IntelliJ IDEA

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK)
- IntelliJ IDEA or another Java-compatible IDE
- Basic understanding of Java programming

### Clone the Repository

```bash
git clone https://github.com/stackyash18/Payroll_Management_System_Using_Core_Java.git
```

Navigate to the project directory:

```bash
cd Payroll_Management_System_Using_Core_Java
```

### Run the Project

1. Open the project in IntelliJ IDEA.
2. Configure the appropriate JDK.
3. Locate the Java class containing the `main()` method.
4. Run the main class to execute the application.
